# Jetson GMSL Kernel


Linux4Tegra Kernel sources for ZED GMSL camera lineup.

## Supported Jetpack Version 
- Jetpack 5.1.1 | L4T 35.3
- Jetpack 5.1.2 | L4T 35.4
- Jetpack 6.0   | L4T 36.3
- Jetpack 6.2.1 | L4T 36.4
- Jetpack 6.2.2 | L4T 36.5
- Jetpack 7.0   | L4T 38.2
- Jetpack 7.1   | L4T 38.4
- Jetpack 7.2   | L4T 39.2

## Reference Design Guide
In order to develop your driver, you first need to make sure your architecture is compatible with our driver implementation.
